# Sales-Dashboard
1. Project Title / Headline
Sales Aanlysis: A dynamic, interactive data visualization tool built to explore sales across different regions and of different products of different category.
2. Short Description / Purpose
This Sales Dashboard is visually engaging and designed to provide visual overview of sales with respect to different regions and for different category of products.
The dashboard focuses on highlighting the sale of different products of different category according to Region and other factors.
New Columns such as Performance and Profit_Margin are also made in order to get insights.
4. Tech Stack
• 🐍 Python- Used for Data Cleaning and finding insights from data.
• 📊 Power BI Desktop – Main data visualization platform used for report creation.
• 📁 File Format – .pbix for development and .png for dashboard previews.
5. Data Source
Source: Kaggle
Data on sales of products of different categories such as Office, Electronics and Accessories.
Data contains information regarding sales such as : Order Date,Product Name,Category,Region,Quantity,Sales,Profit.
